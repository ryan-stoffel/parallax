# Security

Report vulnerabilities privately through [GitHub's private vulnerability reporting](https://github.com/ryan-stoffel/parallax/security/advisories/new), not in a public issue or PR.

Include the affected version or commit, the OS, steps to reproduce, and what an attacker could do. We reply in the advisory and credit you when the fix ships, unless you'd rather stay anonymous.

Fixes go to the latest nightly and the latest stable release. Older releases don't get fixes.
